What is spintax? Examples for DMs and outreach

Spintax (spin syntax) is a way of writing text with alternatives inside curly braces, separated by pipes, so software can pick one option each time it sends. Writing {Hi|Hey|Hello} means each person randomly gets Hi, Hey or Hello.

The short answer

  • Spintax looks like {option one|option two|option three}. One option is chosen at random per message.
  • You can nest it: {Hi|Hey} {there|{firstname}} works.
  • Combine it with placeholders like {firstname} for messages that read naturally and vary.
  • Every option must make sense in the sentence. Read several outputs before sending.
  • Spintax varies wording. It does not make an irrelevant message relevant.

What spintax is

Spintax is short for spin syntax, a marked-up version of text that tells software which parts can change. It started in content spinning, where it was used to generate many versions of an article, as Wikipedia's article spinning entry describes. In outreach, it is used for something more modest: making sure a message sent to many people does not read word for word the same each time.

That matters on Instagram because Meta's spam policy names repetitive content as a spam signal, and because people can tell when they are getting a copied script.

The syntax

To count possible versions, multiply the number of options in each block. {Hi|Hey|Hello} {firstname}, {love|really like} your {feed|page} has 3 x 2 x 2 = 12 versions.

  • Curly braces mark a spin block: {...}
  • Pipes separate the options: {Hi|Hey|Hello}
  • One option is picked at random each time the text is generated.
  • Nesting puts a spin block inside an option: {Hi|Hey} {there|{again|once more}}
  • Empty options let a word sometimes disappear: {really |}love this. Watch the spacing.

Examples

A simple opener:

{Hi|Hey|Hello} {firstname}, {loved|really liked|enjoyed} your post about {topic}.

A full first DM for a coach:

{Hey|Hi} {firstname}! {Saw|Noticed} you {just started|recently started} your fitness journey, {that is a big step|good for you}. {Quick question|Curious}: {what is the hardest part so far|what has been the toughest bit}?

A follow-up:

{Just bumping this|Quick nudge} in case it got {buried|lost} in your requests, {firstname}.

Spintax plus placeholders

Placeholders also use curly braces but have no pipes. {firstname}, {fullname} and {username} are replaced with the person's details instead of a random option. Combined with spintax, you get messages that are both personal and varied.

Plan a fallback for when a first name is missing or is clearly a brand name. Writing {Hey {firstname}|Hey there} hides the problem sometimes but not always, so check how your tool handles empty values and preview real outputs.

Common mistakes

  • Options that change the meaning. {I can help|I will double} your sales is two very different promises.
  • Grammar that breaks. {a|an} {idea|plan} can produce 'a idea'. Spin whole phrases instead of single articles.
  • Missing or extra braces and pipes. One unclosed brace can print the raw code to your recipient.
  • Spaces in the wrong place. {Hi |Hey} creates a double space in one version only.
  • Too many options in every block. Two or three good options beat ten awkward ones.
  • Never previewing. Always read at least five or six generated versions out loud.

Questions

Does spintax stop Instagram from flagging my messages?

No one can promise that. Spintax reduces identical text, which Meta names as a spam signal, but volume, pacing, links and how people react to your messages matter too.

How many variations should a message have?

Enough that people near each other in your list rarely get the same version. A few spin blocks with two or three options each usually gives dozens of combinations.

Can I use spintax in email too?

Yes, most cold email tools support the same {a|b} format. The same rules apply: every option must read well and mean the same thing.
