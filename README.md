# IG Outreach Pro — marketing site

Static marketing site for **IG Outreach Pro**, a Chrome extension for personalized
Instagram DM outreach at scale. Lives at [igoutreachpro.com](https://www.igoutreachpro.com).

- **Extension:** [Chrome Web Store](https://chromewebstore.google.com/detail/ig-outreach-pro/iabflpjdaaaljedkocccimhfjonakcon) — v2.3.2, 5.0★
- **Stack:** hand-written HTML + CSS + vanilla JS. No build step, no framework, no runtime dependencies.
- **Hosting:** Vercel (static).

The redesign (Sep 2026) brings back a pricing section: Free (1 campaign, 10 DMs/day) and

## Layout

The landing page follows gojiberry.ai's section structure and visual language (corner
brackets, dot headlines, numbered sticky cards, 3-step rail, expanding feature carousel,
"replaces your stack" diagram, stats + testimonial marquee, hub diagram, two-card pricing,
gradient CTA). The copy, icons and diagrams are our own. None of their text, logos, images
or claims are reused.

## Videos

All four videos are click-to-load facades: a self-hosted poster frame plus a play button,
which swaps in a `youtube-nocookie.com` iframe on click. Nothing is requested from YouTube
until the visitor asks for it, and hovering preconnects so playback still starts quickly.

The hero walkthrough uses `.player.player-wide` (16:9); the testimonials use the base
`.player` (9:16). The wide variant needs the doubled class for specificity — `.player` is
defined later in the stylesheet and would otherwise win on source order.

To regenerate a testimonial poster frame:

```sh
yt-dlp -f "bv*[height<=1080]+ba/b" -o "vid.%(ext)s" "https://youtube.com/shorts/<ID>"
ffmpeg -ss 3 -i vid.webm -frames:v 1 \
  -vf "scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280" \
  -q:v 2 assets/img/testimonial-N.jpg
```

## Generated pages

`data/niches.json` is the single source of truth for every DM template. After editing it (or the
shared nav/footer in `tools/build.py`), run:

```sh
python3 tools/build.py
```

That regenerates `assets/js/niches.js`, the nav/footer/playground blocks in `index.html`
(between `<!-- @@name -->` markers — don't hand-edit inside them), the templates hub
`instagram-dm-templates/index.html`, one SEO page per niche under `instagram-dm-templates/`,
the shell of `support.html` / `privacy.html` / `terms.html` (their body copy is preserved
verbatim), `404.html`, and `sitemap.xml`. Commit the generated output; Vercel serves it as-is.

## Local preview

```sh
python3 tools/serve.py        # http://localhost:8477
```

It mimics Vercel's `cleanUrls` and `404.html`, so `/instagram-dm-templates/coaches` works locally.

## Deploying

Pushes to `main` deploy to production on Vercel. `cleanUrls` is on, so `/privacy.html`
serves as `/privacy` — internal links use the `.html` form and Vercel normalises them.

## Conventions

- Colours come from the custom properties at the top of `site.css`. Don't hard-code hexes
  in markup; add a token.
- The Instagram gradient (`--grad`) is an **accent**, not a background wash. It belongs on
  small surfaces: primary buttons, numerals, single words, 1px rules.
- Every section is `.rv` (reveal-on-scroll) with optional `.rv-d1`–`.rv-d5` stagger delays.
- Media queries are ordered widest → narrowest so the narrow ones win.
- Keep the page dependency-free. The only external request is the Google Fonts stylesheet.

## Conversion features (Sep 2026)

- **Niche picker** (hero): Coaches' clients / Business owners / Home buyers / Creators / Locals.
  Switches the hero typer, the playground template and the template library. Stored in
  `localStorage` (`igop-niche`) as a convenience only.
- **DM playground** (`#try`): the extension's own spintax engine, ported from `content.js`
  (`{firstname}` `{fullname}` `{username}`, nested `{a|b}`). Keep it in sync if the syntax changes.
- **Savings calculator + comparison** (`#savings`): setter mode and do-it-yourself mode.
- **Template library** (`#templates`): all copy lives in the `NICHES` object in `landing.js`.
- **Sticky mobile CTA**: shows after the hero, hides at the final CTA.
- **Install attribution**: every Chrome Web Store link gets `utm_source=igoutreachpro.com`,
  `utm_medium=landing`, `utm_campaign=<section id>` at runtime. See the Web Store developer
  dashboard's acquisition stats to see which section drives installs.
